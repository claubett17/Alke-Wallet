# 📖 Descripción del Proyecto

Alke Wallet es una aplicación web de billetera digital desarrollada como proyecto del **Módulo 2: Fundamentos del Desarrollo Front-End**.

Permite a los usuarios gestionar su dinero de forma simple y segura, realizando depósitos, transferencias y visualizando el historial de movimientos.

---

## 🚀 Funcionalidades

- Registro e inicio de sesión de usuario
- Visualización de saldo disponible
- Depósito de dinero
- Envío de dinero a contactos
- Administración de contactos (agregar, seleccionar y eliminar)
- Historial de transacciones (ingresos y egresos)
- Interfaz responsive con Bootstrap

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- LocalStorage (simulación de persistencia de datos)

## 🧠 Consideraciones

- No se permite enviar dinero si el saldo es insuficiente
- No se permiten formularios vacíos
- El saldo se actualiza dinámicamente en cada transacción
- Todos los movimientos quedan registrados en el historial
